# 四年级上册生字复习工具实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 构建一个可安装到 iPad 与 iPhone 主屏幕、完全在本地判定手写笔迹并支持离线复习的四年级上册生字静态 Web 应用。

**Architecture:** React + TypeScript 单页应用通过 Hash 路由组织首页、认读、书写、总结和许可页面；教材内容与 413 个汉字的笔画数据在构建期校验、生成并由 Service Worker 全量预缓存。手写判定拆成不依赖 React 的预处理、单笔匹配和整字分类模块；笔迹只存在内存，学习进度写入版本化 `localStorage`。

**Tech Stack:** React、TypeScript、Vite、Hanzi Writer、`vite-plugin-pwa` + Workbox、Vitest、React Testing Library、Playwright WebKit、GitHub Actions、GitHub Pages。

**Spec:** `docs/superpowers/specs/2026-11-06-四年级上册生字复习-design.md`

## Global Constraints

- 适用教材：统编版义务教育教科书·语文四年级上册，根据 2022 年版课程标准修订，2024 年审核。
- 固定数据量：27 课、4 个语文园地、31 个分组、识字表 265 条目、识字表计数 250 字、蓝色多音字 15 条目、写字表 250 条目、两表去重后 413 个目标字。
- iPad 与 iPhone 均提供完整功能，不制作功能缩减的手机版；支持横竖屏和 iOS/iPadOS Safari。
- 认读固定使用识字表；书写来源为 `writing`、`reading`、`both`，默认 `writing`，写字表为空时必须可见地提示并自动切换 `reading`。
- 书写判定必须同时检查笔画数量、字形、笔顺和每一笔方向；无法可靠确认时返回 `unclear`，不得直接判错。
- 初始判定阈值必须集中在独立配置：平均距离 `350`、起终点距离 `250`、曲线形状 `0.4`、最小长度比例 `0.35`，坐标尺度为 `1024×1024`。
- 原始笔迹、截图和单笔匹配明细不得上传、写入 `localStorage` 或 `sessionStorage`。
- 首次联网加载后可完全离线完成认读、书写、标准笔顺动画、进度保存和使用设备自带语音的朗读。
- 页面使用 Hash 路由；部署为免费 GitHub Pages，不使用 NAS、后端、数据库、账号、统计或广告服务。
- 设计令牌固定为：暖白 `#FFF9F7`、奶油粉 `#FBE8EC`、樱粉 `#D96C8A`、深梅 `#7B4051`、薄荷绿 `#78BFA4`、柔和边框 `#EBCBD3`。
- “小桃猫”只做原创本地 SVG 装饰，不覆盖田字格；所有交互目标至少 `44×44 CSS px`。
- 田字格使用 Pointer Events、Pointer Capture 与 `touch-action: none`；页面其他区域保持自然滚动。
- 语音使用 `SpeechSynthesisUtterance`，语言 `zh-CN`、语速 `0.75`，只在用户点击后播放；不可用时保留拼音和完整练习流程。
- 必须保留 Hanzi Writer MIT 许可和完整 Arphic Public License 文本，并在产品内提供“关于与许可”页面。
- 教材扫描页只用于 `work/` 中的人工核对，不得进入仓库生产文件、`public/` 或构建产物。

```ts
  unit: string;
  title: string;
  lessonNo?: number;
  sourcePage: number;
  reading: PracticeItem[];
  writing: PracticeItem[];
};

  schemaVersion: 1;
  contentVersion: string;
  edition: string;

    gardens: 4;

    readingItems: 265;

    writingItems: 250;

  };
```

```ts
// src/content/sources.ts
import type {
  ContentGroup,
  PracticeItem,
  ResolvedWritingSource,
  WritingSource,
  WritingSourceOption,
} from "./types";

const labels: Record<WritingSource, string> = {
  writing: "仅写字表",
  reading: "仅识字表",
  both: "写字表和识字表都有",
};

export function getWritingItems(
  group: ContentGroup,
  source: WritingSource,
): PracticeItem[] {
  if (source === "writing") return [...group.writing];
  if (source === "reading") return [...group.reading];

  const seen = new Set<string>();
  return [...group.reading, ...group.writing].filter((item) => {
    if (seen.has(item.char)) return false;
    seen.add(item.char);
    return true;
  });
}

export function getWritingSourceOptions(
  group: ContentGroup,
): WritingSourceOption[] {
  return (Object.keys(labels) as WritingSource[]).map((source) => {
    const count = getWritingItems(group, source).length;
    return { source, label: labels[source], count, disabled: count === 0 };
  });
}

export function resolveWritingSource(
  group: ContentGroup,
  requested: WritingSource,
): ResolvedWritingSource {
  const requestedItems = getWritingItems(group, requested);
  if (requestedItems.length > 0) {
    return { source: requested, items: requestedItems, switched: false };
  }

  if (requested === "writing" && group.reading.length > 0) {
    return {
      source: "reading",
      items: getWritingItems(group, "reading"),
      switched: true,
      notice: "本课没有写字表内容，已切换到仅识字表",
    };
  }

  return { source: requested, items: [], switched: false };
}
```

`hash-router.ts`：

```ts
import { useSyncExternalStore } from "react";

export type PracticeMode = "read" | "write";
export type Route =
  | { name: "home" }
  | { name: "practice"; groupId: string; mode: PracticeMode; retry: boolean }
  | { name: "summary"; groupId: string; mode: PracticeMode }
  | { name: "about" };

export function parseHash(hash: string): Route {
  const raw = hash.replace(/^#/, "") || "/";
  const [pathname, query = ""] = raw.split("?");
  const params = new URLSearchParams(query);
  if (pathname === "/") return { name: "home" };
  if (pathname === "/about") return { name: "about" };
  const match = pathname.match(/^\/lesson\/([^/]+)\/(read|write|summary)$/);
  if (!match) return { name: "home" };
  const [, groupId, section] = match;
  if (section === "summary") {
    const mode = params.get("mode");
    return mode === "read" || mode === "write"
      ? { name: "summary", groupId, mode }
      : { name: "home" };
  }
  return {
    name: "practice",
    groupId,
    mode: section,
    retry: params.get("retry") === "1",
  };
}

export function toHash(route: Route): string {
  if (route.name === "home") return "#/";
  if (route.name === "about") return "#/about";
  if (route.name === "summary") {
    return `#/lesson/${route.groupId}/summary?mode=${route.mode}`;
  }
  const retry = route.retry ? "?retry=1" : "";
  return `#/lesson/${route.groupId}/${route.mode}${retry}`;
}

function subscribe(callback: () => void) {
  window.addEventListener("hashchange", callback);
  return () => window.removeEventListener("hashchange", callback);
}

export function useHashRoute(): Route {
  return useSyncExternalStore(
    subscribe,
    () => parseHash(window.location.hash),
    () => ({ name: "home" }),
  );
}

export function navigate(route: Route): void {
  window.location.hash = toHash(route);
}
```

```ts
import type { ContentFile } from "./types";
import type { CharacterFileData } from "../handwriting/types";

type Fetcher = (input: RequestInfo | URL, init?: RequestInit) => Promise<Response>;
let contentPromise: Promise<ContentFile> | undefined;
const characterPromises = new Map<string, Promise<CharacterFileData>>();

function assetUrl(path: string): string {
  return `${import.meta.env.BASE_URL}${path}`;
}

async function fetchJson<T>(url: string, fetcher: Fetcher): Promise<T> {
  const response = await fetcher(url);
  if (!response.ok) throw new Error(`内容加载失败（${response.status}）`);
  return (await response.json()) as T;
}

export function loadContent(fetcher: Fetcher = fetch): Promise<ContentFile> {
  contentPromise ??= fetchJson<ContentFile>(assetUrl("content.json"), fetcher);
  return contentPromise;
}

export function loadCharacter(
  char: string,
  fetcher: Fetcher = fetch,
): Promise<CharacterFileData> {
  const cached = characterPromises.get(char);
  if (cached) return cached;
  const promise = fetchJson<CharacterFileData>(
    assetUrl(`characters/${encodeURIComponent(char)}.json`),
    fetcher,
  ).catch((error: unknown) => {
    characterPromises.delete(char);
    throw error;
  });
  characterPromises.set(char, promise);
  return promise;
}

export function clearLoadCacheForTests(): void {
  contentPromise = undefined;
  characterPromises.clear();
}
```

- [ ] **Step 3: 实现会话语义**

`recognitionReducer` 规则：

- `reveal` 只把 `revealed` 设为 `true`；已完成时不处理。
- 未 reveal 时收到 `answer` 不得前进。

`createSessionSummary` 接收最终条目结果：

返回 `successCount`、`reviewCount`、`errorItems`。写入 `sessionStorage` 的键为 `cat-vocab-session-summary-v1`，值为 `Record<`${groupId}:${mode}`, SessionSummary>`；存储失败时保留模块内 fallback。重练队列键为 `cat-vocab-retry-queue-v1`，值为 `Record<`${groupId}:${mode}`, string[]>`。两者只能包含 ID、汉字、拼音、结果、错误历史，绝不包含笔迹。

```ts
// src/handwriting/thresholds.ts
export type HandwritingThresholds = {
  meanDistance: number;
  startEndDistance: number;
  shapeDistance: number;
  minimumLengthRatio: number;
  maximumLengthRatio: number;
  minimumDirectionSimilarity: number;
  minimumPointCount: number;
  minimumStrokeLength: number;
  outOfBoundsTolerance: number;
  maximumInkLengthRatio: number;
  ambiguityRatio: number;
};

export const DEFAULT_THRESHOLDS: HandwritingThresholds = {
  meanDistance: 350,
  startEndDistance: 250,
  shapeDistance: 0.4,
  minimumLengthRatio: 0.35,
  maximumLengthRatio: 2.5,
  minimumDirectionSimilarity: 0.5,
  minimumPointCount: 3,
  minimumStrokeLength: 32,
  outOfBoundsTolerance: 0.08,
  maximumInkLengthRatio: 4,
  ambiguityRatio: 1.15,
};
```

实现 `matchStroke`：

1. 对实际和标准点列各重采样 24 点。
2. `meanDistance` 使用双向点线距离：实际每个点到标准折线的最近距离与标准每个点到实际折线的最近距离取平均。
3. `startDistance`、`endDistance` 为对应端点欧氏距离。
4. 将两组点分别去中心化并按 RMS 半径缩放，再比较对应采样点的平均距离，得到 `shapeDistance`，阈值 `0.4`。
5. `lengthRatio = actualLength / expectedLength`；标准长度小于 1 时按 1 计算。
6. `directionSimilarity` 为实际首尾向量与标准首尾向量的余弦相似度；任一首尾长度小于 5 时返回 1。
7. `score` 为各指标归一化后的加权平均，范围 `0..1`。
8. 正向通过条件必须同时满足：平均距离、起终点、形状、长度上下限和方向相似度阈值。
9. 对反转的实际点列重复同样计算；`reverseMatched` 只能在正向失败时为 true。
10. 不得在 UI 中复制阈值；所有调用默认使用 `DEFAULT_THRESHOLDS`。

- [ ] **Step 3: 实现判定顺序**

`evaluateCharacter` 按以下顺序执行：

1. 预处理学生笔画；原始笔迹为空、全部被过滤或任一点超出 `[-0.08, 1.08]` 时返回 `unclear/ink_quality`。
2. 如果实际总长度大于标准总长度的 `4` 倍，且不存在任一同序号正向匹配，则返回 `unclear/ink_quality`，覆盖随机涂画。
3. 清洗后笔画数与标准笔画数不同，返回 `incorrect/stroke_count`。
4. 对每一笔与同序号标准笔画调用 `matchStroke`。
5. 若任一实际笔画在某个不同目标笔画上通过匹配，并且所有实际笔画可组成无重复的标准笔画索引、但索引序列不是 `0..n-1`，返回 `incorrect/stroke_order`。
6. 若同序号笔画 `reverseMatched`，返回 `incorrect/stroke_direction`。
7. 若所有同序号笔画正向匹配，但整体位置/比例失败，返回 `incorrect/stroke_shape`。
8. 若所有同序号笔画正向匹配且整体位置/比例通过，返回 `correct`，`reasons` 为空。
9. 其余情况若所有不匹配指标都落在阈值的 `1.15` 倍以内，返回 `unclear/ink_quality`；否则返回 `incorrect/stroke_shape`。

整字位置/比例检查：

- 学生点集与标准 `medians` 点集的中心距离不得超过 `350`。
- 两者包围盒对角线比例必须在 `0.45..1.8`。
- 学生包围盒与标准包围盒的交集/学生包围盒面积不得低于 `0.35`，防止只写局部。
- 任一标准 median 之外的孤立笔画不能被忽略。

```ts
// src/features/writing/pointer-geometry.ts
import type { Point } from "../../handwriting/types";

type RectLike = Pick<DOMRect, "left" | "top" | "width" | "height">;

export function normalizePointerPoint(
  clientX: number,
  clientY: number,
  rect: RectLike,
): Point {
  return {
    x: (clientX - rect.left) / rect.width,
    y: (clientY - rect.top) / rect.height,
  };
}

export function toSvgPath(points: Point[], size = 1024): string {
  if (points.length === 0) return "";
  return points
    .map((point, index) =>
      `${index === 0 ? "M" : "L"} ${point.x * size} ${point.y * size}`,
    )
    .join(" ");
}
```

坐标不得截断到 `0..1`，因为 `evaluateCharacter()` 需要识别严重越界并将其判为 `unclear`。只限制屏幕重绘，不修改原始归一化点。

- [ ] **Step 4: 实现 Pointer Events 采集板**

组件必须：

- 只把 Pointer Events 绑定到 `data-testid="writing-board"` 的内部书写面；该面设置 `touch-action: none`，页面其余部分保持默认滚动。
- `pointerdown` 时创建新 `InputStroke`，ID 使用 `crypto.randomUUID()`；环境无该 API 时使用递增序号与时间戳生成。
- 对支持 `setPointerCapture()` 的环境捕获指针；调用前后检查方法存在，避免测试或旧 WebKit 崩溃。
- `pointermove` 优先读取 `event.nativeEvent.getCoalescedEvents?.()`，逐个追加归一化点；不主动去重，留给 `preprocessStrokes()`。
- 只处理当前活动 `pointerId`；多指同时触及时忽略第二个指针。
- `pointerup` 完成当前笔画并释放 capture；`pointercancel` 删除本次未完成笔画，不记录判定。
- 使用 `<svg viewBox="0 0 1024 1024" aria-hidden="true">` 按归一化坐标重绘 `path`。容器尺寸变化无需修改笔迹数据，旋转后自动按新尺寸重绘。
- 提交按钮调用 `onSubmit([...strokes])`；点击“清空重写”只调用 `onChange([])`，不产生进度记录。
- 写完一笔后仍保持整字可提交；`disabled` 为 true 时禁止所有 Pointer Events 和按钮操作，但保留已有笔迹的只读展示。
- 容器使用 `role="group"`、`aria-label="手写田字格，可手指或触控笔书写"`，上方提供可见提示“请按笔顺在田字格中书写”。不要用 `role="application"`。

```tsx
// src/features/writing/WritingBoard.tsx（结构与关键逻辑）
export function WritingBoard({ strokes, disabled = false, onChange, onSubmit }: WritingBoardProps) {
  const strokesRef = useRef(strokes);
  const activePointerRef = useRef<number | null>(null);
  const activeStrokeRef = useRef<string | null>(null);

  useEffect(() => {
    strokesRef.current = strokes;
  }, [strokes]);

  function updateStrokes(next: InputStroke[]) {
    strokesRef.current = next;
    onChange(next);
  }

  function handlePointerDown(event: React.PointerEvent<HTMLDivElement>) {
    if (disabled || activePointerRef.current !== null) return;
    activePointerRef.current = event.pointerId;
    const id = createStrokeId();
    activeStrokeRef.current = id;
    event.currentTarget.setPointerCapture?.(event.pointerId);
    updateStrokes([
      ...strokesRef.current,
      { id, points: [pointerPoint(event)] },
    ]);
  }

  function handlePointerMove(event: React.PointerEvent<HTMLDivElement>) {
    if (disabled || event.pointerId !== activePointerRef.current) return;
    const id = activeStrokeRef.current;
    if (!id) return;
    const events = event.nativeEvent.getCoalescedEvents?.() ?? [event.nativeEvent];
    const added = events.map((item) =>
      normalizePointerPoint(item.clientX, item.clientY, event.currentTarget.getBoundingClientRect()),
    );
    updateStrokes(strokesRef.current.map((stroke) =>
      stroke.id === id ? { ...stroke, points: [...stroke.points, ...added] } : stroke,
    ));
  }

  // pointerUp 结束活动指针；pointerCancel 删除 activeStrokeRef 对应笔画。
  return (
    <section className="writing-board-panel" aria-label="手写练习">
      <p className="writing-board-hint">请按笔顺在田字格中书写</p>
      <div
        data-testid="writing-board"
        className="writing-board"
        role="group"
        aria-label="手写田字格，可手指或触控笔书写"
        onPointerDown={handlePointerDown}
        onPointerMove={handlePointerMove}
        onPointerUp={handlePointerUp}
        onPointerCancel={handlePointerCancel}
      >
        <svg viewBox="0 0 1024 1024" aria-hidden="true">
          {strokes.map((stroke) => (
            <path key={stroke.id} d={toSvgPath(stroke.points)} />
          ))}
        </svg>
      </div>
      <div className="writing-board-actions">
        <Button variant="secondary" disabled={disabled || strokes.length === 0} onClick={() => onChange([])}>
          清空重写
        </Button>
        <Button disabled={disabled || strokes.length === 0} onClick={() => onSubmit([...strokes])}>
          提交
        </Button>
      </div>
    </section>
  );
}
```

`writing.css` 必须设置田字格为正方形、`position: relative`、`touch-action: none`、`user-select: none`、`-webkit-user-select: none`，用 CSS 渐变绘制米字格；`svg` 与书写面完全重合且 `pointer-events: none`。

```ts
export type WritingPhase =
  | "answering"
  | "evaluating"
  | "correct"
  | "incorrect"
  | "unclear";

export type WritingSessionState = {
  items: PracticeItem[];
  index: number;
  phase: WritingPhase;
  strokes: InputStroke[];
  evaluation: Evaluation | null;
  hadError: boolean;
  attempt: number;
  results: SessionSummaryItem[];
  completed: boolean;
  currentItem: PracticeItem | undefined;
};

export type WritingSessionAction =
  | { type: "submit"; strokes: InputStroke[] }
  | { type: "evaluated"; evaluation: Evaluation }
  | { type: "retry" }
  | { type: "skip" }
  | { type: "load-failed" }
  | { type: "next" };
```

状态规则：

- `submit` 只在 `answering` 且 `strokes.length > 0` 时进入 `evaluating`，保留当次笔迹供同一渲染周期判定。
- `evaluated` 只接受 `evaluating`：`correct` 进入 `correct`；`incorrect` 进入 `incorrect` 并设置 `hadError = true`；`unclear` 进入 `unclear`，不设置 `hadError`。每次评价后 `attempt += 1`。
- `retry` 只接受 `incorrect | unclear`，回到 `answering`，清空 `strokes` 和 `evaluation`，保留 `hadError`、`attempt` 与当前索引。
- `next` 只接受 `correct`，追加 `{ result: "correct", hadError }` 并推进；最后一条时 `completed = true`。
- `skip` 只接受 `incorrect`，追加 `{ result: "review", hadError: true }` 并推进；最后一条时完成。
- `load-failed` 只接受 `answering`，表示当前字笔顺数据不可用；不产生评价、不要求笔迹，直接追加 `{ result: "review", hadError: true }` 并推进；最后一条时完成。
- 推进后清空 `strokes`、`evaluation`、`attempt` 和当前字的 `hadError`；完成后 `currentItem` 为 `undefined`。
- reducer 只做纯状态转换，不调用 store、导航或网络。

`WritingPage` 的明确行为：

- 初始来源取 `store.getSnapshot().state.settings.defaultWritingSource`；用 `resolveWritingSource()` 解析。空写字表自动回退到识字表，并把 `notice` 传给 `SourceSelector`。
- 用户点击非禁用来源时调用 `getWritingItems()`，重建会话，并调用 `store.setDefaultWritingSource(source)` 记住以后默认来源。
- `retry=true` 时初始化阶段调用一次 `takeRetryQueue(group.id, "write")`。若队列有有效 ID，从 `both` 有序条目中过滤这些 ID，显示来源“写字表和识字表都有”和 `notice="正在重练本次错字"`；重练不覆盖用户默认书写来源。队列为空时按默认来源开始。
- 只渲染当前条目的拼音和“多音字”标签；答题阶段不渲染目标汉字、`StrokePlayer`、描红或轮廓。

- 判定提交时先 dispatch `submit`，再调用注入的 `evaluate(strokes, characterData)`；`correct` 立即 `store.recordWriting(id, "correct")`，`incorrect` 立即 `store.recordWriting(id, "wrong")`，`unclear` 不写进度。
- 每次有效提交都调用 `store.setRecent(group.id, "write")`。
- `correct` 显示反馈，约 800ms 后自动推进，同时保留可点击的“下一字”；定时器在卸载、手动推进或条目变化时清理，不能重复推进。

- `unclear` 显示反馈，只能重写。重写不调用 `store.recordWriting()`。
- 每次推进后，把 reducer 返回的 `state.results` 保存为真实 `SessionSummary`；完成后调用 `saveSessionSummary()` 并导航到 `#/lesson/{groupId}/summary?mode=write`。
- 没有可练习条目时显示“本课暂时没有书写内容”，提供返回首页链接。
- 页面顶部保留 `ModeSwitch`、`section` 与条目序号；主区域按“拼音—田字格—操作”顺序组织。

```ts
export type PwaHandlers = {

  onNeedRefresh(): void;

type RegisterOptions = {
  immediate?: boolean;
  onOfflineReady?: () => void;
  onNeedRefresh?: () => void;
  onRegisterError?: (error: unknown) => void;
};

type Registrar = (options: RegisterOptions) => (reloadPage?: boolean) => Promise<void>;

export function setupPwa(handlers: PwaHandlers, register: Registrar = registerSW) {
```

```ts
export async function chooseSimpleTarget(page: Page) {
  const content = await page.evaluate(async () => {
    const response = await fetch("content.json");
    return response.json() as Promise<{
      groups: Array<{
        id: string;
        writing: Array<{ id: string; char: string; pinyin: string }>;
        reading: Array<{ id: string; char: string; pinyin: string }>;
      }>;
    }>;
  });
  for (const group of content.groups) {
    for (const item of group.writing) {
      const response = await page.evaluate(
        async (char) => fetch(`characters/${encodeURIComponent(char)}.json`).then((r) => r.json()),
        item.char,
      );
      if (response.strokes.length <= 3) {
        await page.evaluate(
          ({ groupId, itemId }) => {
            sessionStorage.setItem(
              "cat-vocab-retry-queue-v1",
              JSON.stringify({ [`${groupId}:write`]: [itemId] }),
            );
          },
          { groupId: group.id, itemId: item.id },
        );
        return { groupId: group.id, item };
      }
    }
  }

export async function drawMedians(page: Page, char: string) {
  const data = await page.evaluate(
    async (value) => fetch(`characters/${encodeURIComponent(value)}.json`).then((r) => r.json()),
    char,
  );
  const box = await page.getByTestId("writing-board").boundingBox();
  if (!box) throw new Error("writing board is not visible");
  for (const median of data.medians as Array<Array<{ x: number; y: number }>>) {
    const [first, ...rest] = median;
    if (!first) continue;
    await page.mouse.move(box.x + (first.x / 1024) * box.width, box.y + (first.y / 1024) * box.height);
    await page.mouse.down();
    for (const point of rest) {
      await page.mouse.move(
        box.x + (point.x / 1024) * box.width,
        box.y + (point.y / 1024) * box.height,
        { steps: 2 },
      );
    }
    await page.mouse.up();
  }
}
```

```yaml
# .github/workflows/deploy.yml
name: Deploy to GitHub Pages

on:
  push:
    branches: [main]
  workflow_dispatch:

permissions:
  contents: read
  pages: write
  id-token: write

concurrency:
  group: pages
  cancel-in-progress: true

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 22
          cache: npm
      - run: npm ci
      - run: npm test -- --run
      - run: npx playwright install --with-deps webkit
      - run: npm run test:e2e
      - uses: actions/configure-pages@v5
      - name: Build for repository subpath
        env:
          VITE_BASE_PATH: /${{ github.event.repository.name }}/
        run: npm run build
      - uses: actions/upload-pages-artifact@v3
        with:
          path: dist

  deploy:
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    runs-on: ubuntu-latest
    needs: build
    steps:
      - name: Deploy
        id: deployment
        uses: actions/deploy-pages@v4
```

```js
// scripts/verify-dist.mjs
import fs from "node:fs";
import path from "node:path";

const dist = path.resolve("dist");
const required = [
  "index.html",
  "content.json",
  "manifest.webmanifest",
  "sw.js",
  "licenses/HanziWriter-MIT.txt",
  "licenses/ARPHICPL.txt",
];
for (const file of required) {
  if (!fs.existsSync(path.join(dist, file))) throw new Error(`missing dist/${file}`);
}

const content = JSON.parse(fs.readFileSync(path.join(dist, "content.json"), "utf8"));
if (content.groups.length !== 31) throw new Error("expected 31 groups");
const chars = fs.readdirSync(path.join(dist, "characters"))
  .filter((name) => name.endsWith(".json") && name !== "index.json");
if (chars.length !== 413) throw new Error(`expected 413 character files, got ${chars.length}`);
if (content.counts.readingItems !== 265 || content.counts.writingItems !== 250) {
  throw new Error("content counts changed");
}

const sw = fs.readFileSync(path.join(dist, "sw.js"), "utf8");
for (const token of ["content.json", "characters/index.json"]) {
  if (!sw.includes(token)) throw new Error(`service worker does not precache ${token}`);
}

console.log(`Verified dist: ${content.groups.length} groups, ${chars.length} characters`);
```
